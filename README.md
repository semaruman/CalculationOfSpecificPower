


# 🏗️ Калькулятор удельных мощностей
> ХАБР: https://habr.com/ru/articles/1031032/

Десктопное приложение для расчёта удельной мощности, тока, момента и потерь на основе табличных данных потребителей. 
Разработано для автоматизации рутинных расчётов в проектных организациях, заменяя ручной поиск в Excel.

**🔧 Всего за 1 день разработки приложение сократило время одного расчёта с нескольких минут до считанных секунд, исключая человеческую невнимательность при поиске нужных табличных данных**

---

## 🎯 Проблема

Крупная строительная компания в Чебоксарах (Чувашгражданпроект) выполняла десятки расчётов ежедневно с помощью Excel-таблиц. 
Сотрудники вручную искали значения в больших таблицах, что приводило к:

- **Потере времени** – до 5 ручных операций на один расчёт
- **Ошибкам невнимательности** – несложно было незаметить нужную строку или столбец со значениями
- **Разрозненности** – разные Excel-файлы для мощности, тока и потерь

---

## 💡 Решение

**Самостоятельное Windows Forms приложение**, которое:

✅ Автоматически находит нужные значения в таблицах и выполняет интерполяцию  
✅ Считает всё в одном месте – мощность, ток, момент, потери  
✅ Снижает вероятность ошибки невнимательности до нуля  
✅ Работает без установленного .NET – запускается с флешки  

---

## 🚀 Возможности

- **Умная интерполяция** – автоматический подбор min/max значений из таблицы
- **4 типа потребителей** – электроплиты, природный газ, сжиженный газ, садовые домики
- **Полный расчёт**:
  - Удельная мощность (P_уд) с точностью до 3 знаков
  - Ток (I) на основе cos φ
  - Момент (M) по длине ЛЭП
  - Потери с учётом сечения и материала (алюминий/медь)
- **Удобный интерфейс** – выбор из выпадающего списка и ввод чисел
- **Портативность** – один .exe файл, запуск без установки
